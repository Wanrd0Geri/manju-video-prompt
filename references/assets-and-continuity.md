# 资产合同与跨镜连续性

## 分镜记录

为每个源镜头建立内部 ShotRecord：

- 原镜号、时长与 `duration_source: exact | estimated`；
- 景别、角度和摄影机模式；
- 可见角色、道具和环境锚点；
- 左右、前中后景、朝向、视线、遮挡和接触点；
- 可拍到的动作；
- 对白说话人、原句和画内/画外；
- 环境声与局部动作声；
- 显式转场；
- 镜头终态与叙事目的。

缺少时长时才估算；未写转场时留待编译阶段使用硬切。

## 素材职责

按上传顺序建立 AssetMap，每项素材记录最终标签、语义名称、可读状态、授权维度、`version_state: active | retired` 和适用的 `source_cut_scope`。同一语义职责在同一个 cut 内只有一个当前有效版本；换装、受伤或道具破损等来源明确的版本可以绑定互不重叠的 cut 范围。用户替换素材时，被替换版本转为 `retired`，只保留追踪证据，不再进入其原适用范围的当前提示词。

| 素材 | 默认控制字段 |
|---|---|
| 角色图 | 身份、脸、发型、年龄感、服装、稳定随身物 |
| 场景图 | 地点、建筑、布局、材质，以及用户指定的光线或风格 |
| 道具图 | 外形、材质、颜色和用户指定的状态 |
| 音频 | 目标角色的音色、年龄感、节奏和说话气质 |

动作、表情、镜头、剧情、天气变化、当前持有人和目标对白由分镜或用户要求控制。静态素材没有展示某项变化，不构成冲突。

每个生成段内，同一素材标签只绑定一次，并写清该段所需的可执行职责；不同生成段独立生成时，分别重复绑定各自会使用的素材。例如：

`图片1：沈清霜的外貌、发型与白色衣裙。`

`音频1只参考沈清霜的音色、年龄感和克制的说话气质。`

## 冲突算法

1. 找到分镜锁定的字段和值；
2. 找到素材被授权控制的字段和值；
3. 两者控制同一字段且取值互斥时判为硬冲突；
4. 素材未控制该字段时，以分镜为准；
5. 硬冲突通过更换素材或让用户确认修订该字段解决。

角色身份不明、同一角色存在未说明的多套服装、关键道具状态相反、场景布局与镜头依赖互斥、音色归属不明或上传顺序不确定，均进入阻断分支。

## SceneState

逐 cut 维护：

- 角色：身份、服装、发型、伤势、干湿、姿势、位置、朝向和视线；
- 空间：世界位置、画面位置、前中后景、动作轴、遮挡；
- 道具：形态、开合或破损、位置、持有人、左右手、接触点；
- 动作：动作身份、当前阶段、速度方向、完成状态；
- 环境：天气、风水烟雾方向、光线和仍在衰减的扰动；
- 摄影：机位、景别、运动，以及切换机位后仍应保持的世界关系。

每个镜头写可见初态、变化和终态。下一镜只继承理解事件所需的状态子集。换机位可以改变画面左右，人物在世界中的相对关系保持一致。

分镜、已确认项目资料或被授权的场景素材给出光线时，记录光源在世界中的方向、主要受光面、阴影侧、背景曝光和仍在变化的反射或亮度。切换机位后重新计算摄影机看到的明暗关系；固定光源不能随摄影机移动，只有来源明确出现移动光源或光照变化时才更新灯光状态。来源没有锁定具体灯位时，只维持前后镜头一致，不新增复杂灯光设计。

## 复杂动作状态机

递交、拥抱、拿取、拔出、推门、跌倒、追逐和碰撞按四阶段处理：

1. 初态：人物、道具与接触关系；
2. 接触：首先发生接触的身体部位或道具；
3. 变化：重量、持有人、方向或姿态发生变化；
4. 终态：单帧可判断动作是否完成。

切镜发生在动作中途时，下一镜从当前阶段继续。最终提示词使用自然动作句，不显示状态机标题。

## 修改影响与完整重编

修改已编译结果前，读取最新完整受影响分镜范围、当前生成段、有效素材和相邻边界。先定位最小改变字段，再沿依赖关系检查到下一个稳定边界：

来源保持不变的提示词修复不得改变当前分镜的 `exact` 事实。只有用户明确提交修订后且已批准的新分镜时，才更新当前源合同并允许其新增、删除、重排 cut 或替换对应时长；随后仍按新源事实重新计算映射、连续性与编组，不能顺带改写未修订内容。

- 人物、位置、朝向、视线、机位或景别改变：复查裁切、前后景、遮挡、动作轴、接触路线、受光面、终态和下一镜入口；
- 动作、终态、道具状态或持有人改变：复查动作阶段、左右手、接触点、时间、结果和后续继承；
- 对白、说话人或台词时间改变：复查原句次数、口型可见时间、听者反应、画内外接力和切镜分配；
- 光源、天气、风水烟雾方向或环境扰动改变：复查所有持续可见镜头及其残余状态；
- 素材职责、上传顺序或有效版本改变：复查该素材授权字段覆盖的全部生成段，旧版本保持停用；
- 时长、cut 数或生成段编组改变：重算相关时间轴、动作和对白容量、段首段尾状态。

未受影响的 `exact` 与 `semantic` 事实保持锁定。影响跨越 cut 或生成段时继续扩展，直到段首状态与上一稳定边界、段尾状态与下一稳定边界都一致。内部可以字段级修复，外部至少返回完整受影响生成段；没有最新完整上下文时先索取，不输出孤立替换句，也不凭记忆重建未改内容。

## 最小恢复

| 失败 | 修复 |
|---|---|
| 身份或服装漂移 | 修正素材职责和角色语义名称 |
| 道具交接失败 | 明确初始持有人、共同接触和唯一终态 |
| 动作重复 | 把下一镜起点改为上一镜当前阶段 |
| 空间跳变 | 校正世界位置、动作轴、朝向和视线 |
| 资产状态冲突 | 更换资产或采用用户确认后的状态 |
| 光线随切镜翻转 | 固定世界光源方向并重算当前机位可见受光面 |
| 修改后相邻镜头失配 | 扩大影响范围到下一稳定边界并完整重编相关生成段 |
