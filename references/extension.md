# 视频延长

仅在向后延长可读取的源视频时读取本文件；通用镜头写法以 [compile-core.md](compile-core.md) 为准。

## 尾段证据

检查最后一个完整动作段而不只截取单张尾帧，内部建立 `SeamState`：最后机位与运动阶段、构图和可见性、人物姿态与接触、伤势、道具及持有人、尚未完成的动作、世界光源与本镜受光、焦点，以及仍在延续的对白、呼吸、环境声、字幕和配乐。

实际尾段的 `observed` 状态控制接缝。原提示词只补视频无法确认的身份、前情或声音设定，不能覆盖已经生成的画面。源视频读不清而不同解释会改变新增镜头时阻断，不凭旧提示词猜尾帧。

## 延长栏

`视频延长：`固定完成三件事：绑定源视频；用一句话概述源视频已经发生的故事；写理解新增动作所必需的最小接缝状态。前情每次必写，但不复述原视频全部镜头。

前情只概括已经完成的事件，不承载“仍在、正在、尚未”等当前状态；当前状态只写进接缝，同一事实不得在前情和接缝各说一次。

```text
视频延长：
向后延长视频1；该视频讲述[一句话前情]。新增片段承接视频结尾的[最小必要接缝]继续。
```

先从新增镜头1的第一个新动作反推最小依赖集，再写接缝。只有删除后会让该动作身份不明、物理跳变或状态断裂的事实才能进入；稳定外貌、整套站位、整套光线、一般环境声和已经结束的动作不进入接缝，只在所属素材、全局控制或第一个相关镜头中建立。

## 新增镜头1与最小锚点

新增时间轴从 0.0 秒开始，镜号使用 `新增镜头1`、`新增镜头2`……。新增镜头1直接呈现接缝之后发生的第一个变化，不回放原片。

接缝栏和新增镜头1只共享执行第一个新动作所必需的最小依赖簇。例如批准的新动作是捂伤时，接缝可写“匕首仍留在姜知意小腹”，新增镜头1可写“姜知意弓身捂住匕首周围的伤口”。复杂动作确需人物、道具与接触关系共同成立时可保留这些依赖；与动作无关的姿态、整套站位、机位、光线和声音不得再次罗列。

新增片段的终态遵循编译核心：来源明确或后续承接需要时写入所属新增镜头，不另设“新增终点”。

## 素材、位置与声音

角色图可继续锁定身份与造型，不能替代尾段站位证据。若新增镜头依赖尾段没有交代的多人精确几何，按 [assets-and-spatial.md](assets-and-spatial.md) 判断是否需要新的站位图或合成场景图。

延长默认继承源视频已有的字幕、配乐和持续声音状态；只有用户明确改变时才覆盖。普通环境音、对白和动作声写入所属新增镜头；`声音：`只用于绑定额外提供的音频或音色素材。

## 接缝自审

- 一句话前情讲已发生的事件，接缝讲开始续写所需的当前状态；
- 新增镜头1产生新变化，没有重演原片或整段复述接缝；
- 尾段动作速度、人物接触、道具、伤势、机位方向和持续声音没有跳变；
- 任何新站位都有可读证据或可见移动过程。
