# 素材职责与多人空间

有角色、场景、道具、音频或源视频任一素材，或镜头涉及多人位置、POV、遮挡和跨镜状态时读取本文件。

## AssetMap

按上传顺序记录素材标签、语义名称、可读状态、有效版本、授权维度、适用镜头和证据状态。同一范围内同一职责只能有一个有效来源；每项素材在最终提示词中只绑定一次，时间轴随后使用人物或物体名称。

| 素材 | 默认授权职责 | 不能据此确定 |
|---|---|---|
| 源视频 | 已生成声画、尾段接缝和既有连续状态 | 新增剧情、未出现的身份事实 |
| 角色/主体图 | 身份、脸、发型、年龄感、服装和稳定随身物 | 当前站位、动作、道具持有人 |
| 场景图 | 地点、环境布局、材质，以及明确授权的光线或风格 | 人物位置，除非用户明确授权图中站位 |
| 站位图/合成场景图 | 世界位置、屏幕投影、深度、朝向、路径、遮挡和接触关系 | 身份细节，除非同时被授权 |
| 道具图 | 外形、材质、颜色和明确展示的状态 | 当前持有人、动作与剧情结果 |
| 音频 | 指定人物的音色、年龄感、节奏和说话气质 | 台词内容、发声次数和镜头声音事件 |

素材中顺带出现的内容不自动获得控制权。冲突时按控制维度拆分，而不是让一张图同时决定身份、场景和站位；互斥版本无法定夺时阻断。

## 是否需要新的位置参考

先检查已批准分镜或源视频是否清楚交代新增构图所需的世界左右、远近、朝向、路径和遮挡。信息充分时直接继承，不为“加强一致性”重复垫图。

若多人高风险镜头依赖尚未出现的精确关系，应补一张明确标注人物身份、世界位置、朝向与摄影机方向的站位图或合成场景图。它的作用是授权空间拓扑，不是替换角色身份图。若新图与源视频尾段位置冲突，新增片段必须展示可行的移动过程，否则阻断。

## 世界状态与画面投影

世界位置是人物在场景中的真实关系；屏幕左右、前后景和遮挡是该世界状态经过当前摄影机投影后的结果。每次切镜按以下顺序重算：

1. 摄影机世界位置、高度和观察方向；
2. 各人物的世界位置、朝向、视线与接触；
3. 投影后的屏幕左右、深度层级和可见范围；
4. 前中后景、遮挡、裁切、面部可见性和焦点。

换到反打机位可以交换屏幕左右，不能让人物瞬间换座或穿过彼此。提示词只写当前机位真实看得到的内容。

## VisibilityState 与 POV

每镜内部把在场人物分为：`full_frame`（主体主要部分入画）、`partial_frame`（仅肩背、手、轮廓等局部入画）和 `offscreen`（仍在场但当前画外）。三类都从 `world_roster` 投影得到，不能因为人物仍在场就把他写进画面。

| 机位 | 可见性边界 |
|---|---|
| 严格第一人称 POV | 摄影机位于视点人物双眼；无镜面时不能看见其后脑、脸或上半身背影，只有视野内合理出现的手脚等局部可见 |
| 越肩 | 摄影机位于观察者肩后；观察者只能以肩背等局部作前景，目标人物通常正面或侧面可见 |
| 双人背面反打 | 摄影机位于两人身后；两人的背影可作前景，前方对象位于中后景 |
| 独立观察机位 | 摄影机不属于任何人物；可见对象由空间、朝向和遮挡决定，不得称为主观视角 |

严格 POV、越肩和双人背面反打不能在同一镜头中混称。若要求“从姜知意视角看四人”，又要求姜知意和陆野两人的背影同时入画，必须改成位于两人身后的独立观察机位或双人背面反打；不能让模型同时满足互斥条件。

## 连续性账本

逐 cut 维护角色造型与伤势、世界位置和朝向、动作阶段、道具形态与持有人、左右手和接触点、固定光源、持续声音。切镜后把账本投影为本镜画面，再按编译核心形成摄影闭包。

任何镜头若无法同时满足摄影机位置、人物朝向、面部可见性、遮挡、焦点和动作，应阻断并给出两种可拍机位方案，不得为容纳所有人物自动改成普通正面群像。
